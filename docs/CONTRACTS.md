# Junie runtime contract

`apply(ctx)` registers local Agent `junie` on Agent API v1. Studio computes `plugin:junie/junie`. The plugin advertises Global and Scoped single chat with streaming and `resume: false`. [Studio SDK Agent types](../sdk/src/agents.ts)

## Engine management

Managed builds are downloaded from the stable release in [JetBrains' official ACP repository](https://github.com/JetBrains/junie-acp-release). Archive names and internal executable locations match the [ACP registry](https://cdn.agentclientprotocol.com/registry/v1/latest/registry.json). The manager validates the exact platform asset and GitHub-published SHA-256 before extraction. The API supplies an exact size. When the API is rate limited, the public GitHub release asset supplies the digest and the download is still subject to a size limit. It accepts only regular archive files and directories, normalizes the Windows release's path separators and rejects traversal, ambiguous Windows names and symlinks. It launches the verified staged executable with its own temporary native directory, confirms its JetBrains build tag and checks its ACP v1 identity before switching the selected engine.

Only the activating Studio account and Profile can request updates, install, upgrade, delete and read the native login command. The engine status can be read independently of native account access so other permitted callers can select Scoped. Studio also enforces its management authorization and serializes maintenance against running turns. Managed health and versions come from the selected executable. Engine versions use the JetBrains tag, for example `4100.11`, while external versions retain the CLI's displayed version.

`engine/current.json` in the plugin data directory stores the selection. An absent pointer allows external discovery. A non-empty `directory` and `version` select the managed build. Both empty strings represent removal and keep later PATH discovery from making a deleted engine appear installed. An explicit `EKKO_JUNIE_EXECUTABLE` always takes precedence, including an invalid override. Pointer replacement is atomic. Failed staging leaves the previous selection active. Removal targets only the selected managed release. It keeps the plugin installed and preserves the native Junie home, credentials, settings and conversations. The selection schema and the owner-only `native-login` RPC are declared in [the JSON contract](../contracts/plugin.json). A fresh update from version 0.1.0 has no managed pointer and preserves external detection.

The manager never installs or removes external CLI files. It resolves the executable behind JetBrains' marked installer launcher and reads the official Windows version marker, avoiding their update wrappers. Explicit custom executables are trusted administrator-supplied programs. The Settings view returns a shell-quoted command for the current executable, with PowerShell quoting on Windows. The login RPC also returns the official Junie wordmark as a data URL for the secondary, attributed vendor reference. The plugin card and Agent card use the original integration icon. The current shared host exposes action flags by Agent definition, so the UI may display a delete button even for an external engine. The backend rejects the request.

## Global and Scoped

Both modes use the same binary discovery and the same workspace and Agent-session identity checks. Mode, account, Profile, session and Agent ID must match at execution. Global also requires the activating account and Profile. The Global catalog comes from `session/new` in a temporary workspace and honors the native `model` and `effort` options. The plugin confirms the selected model and effort before prompting. Authentication-required errors give native sign-in instructions.

Scoped accepts the caller's authorized `run.model` and advertises `chat_completions` to Studio. It creates a private Junie home and custom model profile for the turn. Junie starts with native credential variables, global/project model and configuration discovery, and default skills, MCP, commands and custom agent discovery disabled. The scoped child receives a fresh loopback key rather than the Studio lease. It must confirm the isolated Junie custom model in ACP. The relay checks the path, key and exact selected model, applies the Studio reasoning effort and output limit, and supplies the lease to the Studio gateway only. Scoped accounting is handled by the gateway. Process, relay and private files are cleaned up on completion, cancellation or failure.

## ACP turns

ACP v1 is newline-delimited JSON-RPC over stdio. Raw CLI stderr and ACP error bodies are suppressed. A turn passes the canonical workspace, instructions, prior messages, authorized attachments and run-scoped MCP transports. Junie must confirm `brave_mode=off`. The plugin handles permission requests only from the active native session and maps explicit one-time grants and denials to ACP outcomes. It forwards ordered text chunks, omits raw tool arguments and results and returns one final reply. A cancelled run sends `session/cancel` before closing the process. Global includes native token usage when available.

Studio supplies previous messages to each new native turn, including after restart. Enabling native resume requires separate verification of restart recovery and interruption semantics with a real JetBrains account.
